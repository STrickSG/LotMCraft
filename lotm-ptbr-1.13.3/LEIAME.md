# LOTM PTBR 1.13.3 (uso pessoal)

Versão traduzida do LOTMCraft 1.13.3 para uso pessoal. O mod original é "All Rights Reserved";
este diretório não contém o jar do criador, só o que é preciso para refazer a tradução em cima dele.

- `pt_br.json`: tradução completa (4063 textos), com os nomes da nossa versão (Ministro, Feiticeiro Bizarro, Feiticeiro dos Segredos...).
- `classes-corrigidas/`: poção, receita, característica e menu de receita com o nome montado por formato traduzível ("Poção de Feiticeiro dos Segredos").
- `textos-fixos.tsv` + `ferramenta/Literais.java`: textos em inglês escritos direto no código que vão para a tela, trocados no bytecode (só onde o texto chega à tela; textos usados na lógica ficam intactos).
- `montar.sh`: monta `LOTM-PTBR-1.13.3.jar` a partir do jar original.

O modid continua `lotmcraft`, então mundos da 1.13.3 abrem normalmente. O nome exibido é "LOTM PTBR".
